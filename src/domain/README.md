# src/domain — cálculos e regras

Regras de negócio, sem nenhuma dependência de tela.

- `dinheiro.ts`: valores sempre em centavos inteiros e formatação R$.
- `agregacoes.ts`: totais por mês, imóvel, conta, participante.
- `consolidacao.ts`: "Todos os Produtores" com tratamento de condôminos.
- `irpf.ts`: resultado real x 20%, prejuízo, estimativa, projeção e simulação.
- `documentos.ts` (CPF/CNPJ) e `datas.ts` (datas e feriados).
